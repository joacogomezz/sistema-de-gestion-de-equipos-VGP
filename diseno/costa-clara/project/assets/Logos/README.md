# Logos

El sol estilizado de línea es la marca del sistema. **logo-sol.svg**: sol blanco sobre baldosa dorada (`dorado`, radio 10px) — úsalo en la barra lateral, el ícono de la PWA y la pantalla de inicio de sesión. **sol-blanco.svg**: solo el trazo blanco, para colocarlo sobre `dorado` o sobre superficies oscuras. Tamaño mínimo 24px; deja un margen libre de 1/4 del tamaño. No lo rellenes, no lo recolores fuera de blanco/dorado y no lo acompañes de rayos extra.
