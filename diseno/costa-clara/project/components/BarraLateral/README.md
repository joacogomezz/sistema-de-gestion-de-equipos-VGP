# BarraLateral
Barra lateral colapsable con el logo del sol, las secciones del sistema y, al pie, modo oscuro y colapsar.

- Secciones: Inicio · INVENTARIO (Equipos, Resguardos, Solicitudes de alta) · ALBERCAS (Control de toallas) · BAJAS (Baja individual, Bajas masivas) · CATÁLOGOS (Departamentos, Áreas, Fases) · Reportes · ADMINISTRACIÓN (Usuarios, Respaldo de base de datos), visible solo para Super Administrador.
- Elemento activo: fondo `dorado-suave`, texto e ícono `dorado-texto` y marca vertical `dorado` de 3px en el borde.
- Encabezados de sección en `seccion-menu`. Contador dorado en Solicitudes de alta.
- Ancho `barra-lateral-ancho` (248px) / `barra-lateral-colapsada` (72px, solo íconos con tooltip). Debajo de 1024px se oculta y abre como cajón desde el botón hamburguesa.
